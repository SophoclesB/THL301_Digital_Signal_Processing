## Installation instructions
In order to be able to run the scripts in the LabCode/ directory you need to first install the dependencies\
To do that you need to first make sure uv is installed and create a venv in the root project directory:\
```uv venv```\
Then you can install the dependencies with:\
```uv pip install -r requirements.txt```

---
## Usage instructions
To run each script you need to have Python 3.14.7 installed and in a terminal cd to the LabCode/Lab01/ directory and run:\
```python ex*.py``` where * is the specific exercise number.
